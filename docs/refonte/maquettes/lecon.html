1. Reconnaître un polynôme de degré 2

Définition

f(x) = ax² + bx + c, avec a ≠ 0.

Si a > 0, la parabole est ouverte vers le haut et possède un minimum. Si a < 0, elle est ouverte vers le bas et possède un maximum.

Méthode

  1. Repérer a, le nombre devant x².
  2. Lire son signe.
  3. Conclure sur le sens d’ouverture.

Exemple

g(x) = −x² + 4x : a = −1 < 0, la parabole est tournée vers le bas.

À retenir

Le signe de a donne le sens d’ouverture, avant tout calcul.

Attention

Dans 3 − 2x², a vaut −2, pas 3 : on lit le coefficient de x², où qu’il soit écrit.
