Dans cette leçon

Prérequis

Avant de commencer, vérifie que tu sais :

  • Équations et inéquations : résoudre une inéquation du premier degré.
  • Calcul algébrique : factoriser une expression.

Essaie d’abord seul : une correction ouverte compte comme une aide dans le suivi facultatif.

Ce que tu vas savoir faire

Déterminer le signe d’une fonction affine, dresser le tableau de signes d’un produit ou d’un quotient de facteurs affines, et résoudre des inéquations du type A(x)B(x) ≥ 0 ou A(x)/B(x) > 0.

Besoin d’un coup de pouce ? La méthode en 3 étapes
  1. Factorise l’expression si nécessaire.
  2. Étudie le signe de chaque facteur sur une ligne du tableau.
  3. Applique la règle des signes, puis lis les solutions.

1. Signe d’une fonction affine

f(x) = mx + p (m ≠ 0) s’annule en x₀ = −p/m. Elle est du signe de m à droite de x₀ et du signe contraire à gauche.

Signe de 2x − 6
x−∞ ; 333 ; +∞
2x − 6−0+

Pause mémoire · Affine

Quel est le signe de −3x + 6 pour x > 2 ?

Choisis une réponse.

Voir le raisonnement et la réponse

À droite de 2, l’expression a le signe de −3 : négatif.

2. Tableau de signes d’un produit

Une ligne par facteur, puis une dernière ligne pour le produit : il est positif quand le nombre de facteurs négatifs est pair.

Un produit

(x + 1)(x − 4) est positif sur ]−∞ ; −1] ∪ [4 ; +∞[ et négatif sur [−1 ; 4] : l’inéquation (x + 1)(x − 4) ≥ 0 a pour solutions ]−∞ ; −1] ∪ [4 ; +∞[.

Pause mémoire · Un produit

Combien de facteurs négatifs faut-il pour qu’un produit de trois facteurs non nuls soit positif ?

Choisis une réponse.

Voir le raisonnement et la réponse

Un nombre pair de facteurs négatifs donne un produit positif.

3. Signe d’un quotient

A(x)/B(x) a le même signe que A(x)B(x), mais n’est pas défini là où B(x) = 0 : on marque cette valeur interdite par une double barre dans le tableau.

La valeur interdite

(x − 2)/(x + 5) > 0 a pour solutions ]−∞ ; −5[ ∪ ]2 ; +∞[ : −5 est toujours exclu, même avec une inégalité large.

4. Interpréter en contexte

Le signe d’un bénéfice, d’une différence de coûts ou d’une vitesse indique un gain ou une perte, un tarif plus avantageux, un sens de déplacement.

Un bénéfice

B(x) = (x − 20)(80 − x) est positif pour x ∈ ]20 ; 80[ : l’entreprise est bénéficiaire entre 20 et 80 objets vendus.

5. Vérifier sa compréhension

Résous x² − 9 < 0.

Afficher la correction

x² − 9 = (x − 3)(x + 3) est négatif entre les racines : S = ]−3 ; 3[.

À retenir

mx + p a le signe de m à droite de sa racine. Produit : règle des signes dans un tableau. Quotient : même signe que le produit, avec une valeur interdite toujours exclue.
