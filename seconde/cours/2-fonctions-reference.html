Dans cette leçon

Prérequis

Avant de commencer, vérifie que tu sais :

  • Généralités sur les fonctions : reconnaître une fonction paire ou impaire.

Essaie d’abord seul : une correction ouverte compte comme une aide dans le suivi facultatif.

Ce que tu vas savoir faire

Connaître la définition, la courbe, le sens de variation et le signe des fonctions de référence, et les utiliser pour résoudre f(x) = k et f(x) < k ou comparer des nombres.

Besoin d’un coup de pouce ? La méthode en 3 étapes
  1. Identifie la fonction de référence en jeu.
  2. Utilise sa courbe ou son sens de variation.
  3. Écris les solutions, en tenant compte de l’ensemble de définition.

1. Fonction carré

x ↦ x², définie sur ℝ, est décroissante sur ]−∞ ; 0] et croissante sur [0 ; +∞[. Sa courbe est une parabole symétrique par rapport à l’axe des ordonnées : la fonction est paire.

Une inéquation

x² ≤ 64 équivaut à −8 ≤ x ≤ 8. x² > 9 équivaut à x < −3 ou x > 3.

Démontrer une variation

Si 0 ≤ a < b, alors b² − a² = (b − a)(b + a) > 0, donc a² < b² : la fonction carré est croissante sur [0 ; +∞[.

Pause mémoire · Carré

Quelles sont les solutions de x² = 25 ?

Choisis une réponse.

Voir le raisonnement et la réponse

x = 5 ou x = −5.

2. Fonction inverse

x ↦ 1/x, définie sur ℝ privé de 0, est décroissante sur ]−∞ ; 0[ et sur ]0 ; +∞[. Sa courbe est une hyperbole, symétrique par rapport à l’origine : la fonction est impaire.

Pas de décroissance sur ℝ privé de 0

−1 < 1, et pourtant 1/(−1) = −1 < 1/1 = 1 : la fonction inverse n’est pas décroissante sur ℝ privé de 0 tout entier.

Pause mémoire · Inverse

Comparer 1/3 et 1/7 : lequel est le plus grand ?

Choisis une réponse.

Voir le raisonnement et la réponse

3 < 7 et la fonction inverse inverse l’ordre : 1/3 > 1/7.

3. Fonction racine carrée

x ↦ √x, définie sur [0 ; +∞[, est croissante. Pour x ∈ [0 ; 1], √x ≥ x ; pour x ≥ 1, √x ≤ x.

Une équation

√x = 6 pour x = 36 ; √x ≤ 4 pour x ∈ [0 ; 16].

4. Fonctions cube et valeur absolue

x ↦ x³, définie sur ℝ, est croissante et impaire. Pour x ≥ 1, x³ ≥ x², et pour x ∈ [0 ; 1], x³ ≤ x².

x ↦ |x| vaut x si x ≥ 0 et −x si x < 0 : décroissante sur ]−∞ ; 0], croissante sur [0 ; +∞[, paire. |x − a| = r a pour solutions a − r et a + r.

5. Vérifier sa compréhension

Résous x³ = −27, puis |x + 2| = 5.

Afficher la correction

x = −3 ; puis x + 2 = 5 ou x + 2 = −5, soit x = 3 ou x = −7.

À retenir

Carré : parabole, paire. Inverse : hyperbole, impaire, décroissante sur chaque intervalle. Racine : croissante sur [0 ; +∞[. Cube : croissante, impaire. Valeur absolue : distance à 0.
