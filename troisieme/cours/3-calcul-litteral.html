Dans cette leçon

Prérequis

  • Fractions et nombres relatifs : respecter les priorités avec des relatifs.

Essaie d’abord seul : une correction ouverte compte comme une aide dans le suivi facultatif.

Ce que tu vas savoir faire

Développer et réduire une expression, utiliser la double distributivité et les identités remarquables, factoriser par un facteur commun ou une différence de deux carrés, et traduire un programme de calcul pour démontrer une propriété.

Besoin d’un coup de pouce ? La méthode en 3 étapes
  1. Repère la forme : produit à développer ou somme à factoriser.
  2. Applique une règle à la fois, en écrivant chaque produit.
  3. Réduis, puis vérifie avec une valeur de x.

1. Développer avec la distributivité

k(a + b) = ka + kb et (a + b)(c + d) = ac + ad + bc + bd

Simple et double distributivité

3(2x + 5) − 4(x + 1) = 6x + 15 − 4x − 4 = 2x + 11.

(2x + 3)(x − 4) = 2x² − 8x + 3x − 12 = 2x² − 5x − 12.

Le signe moins

Un signe moins devant une parenthèse change le signe de tous les termes de la parenthèse : −(x − 4) = −x + 4.

Pause mémoire · Une identité

Quel est le développement de (x − 4)² ?

Choisis une réponse.

Voir le raisonnement et la réponse

(x − 4)² = x² − 8x + 16.

2. Les identités remarquables

(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
(a + b)(a − b) = a² − b²

Les appliquer

(x + 3)² = x² + 6x + 9 ; (2x − 5)² = 4x² − 20x + 25 ; (3x + 1)(3x − 1) = 9x² − 1.

Le double produit

(x + 3)² ne vaut pas x² + 9 : il manque le double produit 2 × x × 3 = 6x. Teste avec x = 1 : 4² = 16, alors que 1 + 9 = 10.

Pause mémoire · Factoriser

Quelle est une factorisation de x² − 49 ?

Choisis une réponse.

Voir le raisonnement et la réponse

x² − 49 = x² − 7² = (x − 7)(x + 7).

3. Factoriser

Factoriser, c’est transformer une somme en produit. C’est l’opération inverse du développement.

On cherche un facteur commun à tous les termes, ou on reconnaît une identité remarquable, le plus souvent a² − b² = (a − b)(a + b).

Deux factorisations

6x² + 15x = 3x × 2x + 3x × 5 = 3x(2x + 5).

9x² − 25 = (3x)² − 5² = (3x − 5)(3x + 5).

4. Démontrer avec le calcul littéral

Une lettre permet d’écrire un raisonnement valable pour tous les nombres. Un exemple numérique peut illustrer, mais il ne démontre pas.

Un programme de calcul

Programme : choisir x, ajouter 3, élever au carré, soustraire x². On obtient (x + 3)² − x² = x² + 6x + 9 − x² = 6x + 9. Le résultat est donc toujours un multiple de 3.

Pour montrer qu’une affirmation est fausse, un seul contre-exemple suffit.

5. Vérifier sa compréhension

Développe et réduis (2x + 1)² − (x − 3)(x + 3).

Afficher la correction

(2x + 1)² = 4x² + 4x + 1 et (x − 3)(x + 3) = x² − 9. Donc 4x² + 4x + 1 − x² + 9 = 3x² + 4x + 10.

À retenir

Développer : produit vers somme. Factoriser : somme vers produit. Les trois identités remarquables servent dans les deux sens. Vérifier une égalité avec une valeur de x permet de repérer une erreur.
