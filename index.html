APPLICATION

Calculer une image

La fonction f est définie par f(x) = x + 1. Combien vaut f(2) ?

Voir la réponse et la méthode

Méthode : pour une image, on remplace x par la valeur donnée. Calcul : f(2) = 2 + 1 = 3. Conclusion : f(2) = 3 ; sur le dessin, le point de la droite d’abscisse 2 a pour ordonnée 3.
