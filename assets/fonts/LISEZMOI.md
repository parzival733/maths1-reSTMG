# Polices du site

| Fichier | Police d'origine | Modification |
|---|---|---|
| `stmg-serif-semibold.woff2` | Source Serif 4 (Adobe), graisse 600, taille optique 32 | Instance statique, sous-ensemble des caractères du site |
| `stmg-sans-regular.woff2` | Source Sans 3 (Adobe), graisse 400 | Instance statique, sous-ensemble |
| `stmg-sans-bold.woff2` | Source Sans 3 (Adobe), graisse 700 | Instance statique, sous-ensemble |

Les deux polices sont sous licence SIL Open Font License 1.1 (`OFL-source-serif-4.txt`, `OFL-source-sans-3.txt`). Leur nom « Source » est réservé : les versions réduites portent donc les noms « STMG Serif » et « STMG Sans ».

Sous-ensemble : latin de base, latin-1, ligatures françaises, ponctuation typographique (y compris les espaces insécables) et signes mathématiques présents dans les pages. Les signes absents des polices d'origine, par exemple ₙ, ∪, ∈, ⇔ et ℝ, sont affichés par la police du système.
