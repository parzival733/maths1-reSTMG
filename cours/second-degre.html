Besoin d’un coup de pouce ? La méthode en 3 étapes

En clair : Une parabole décrit la courbe d’une expression ax² + bx + c. Les racines disent où elle rencontre l’axe horizontal.

  1. Cherche si l’expression est factorisée : chaque facteur nul fournit une racine.
  2. Observe le signe de a pour savoir si la parabole monte ou descend de part et d’autre du sommet.
  3. Pour le sommet, cherche le milieu des racines quand tu les connais, puis calcule l’image.

1. Reconnaître un polynôme de degré 2

f(x) = ax² + bx + c, avec a ≠ 0.

Un polynôme du second degré s’écrit f(x) = ax² + bx + c avec a ≠ 0. Sa courbe est une parabole. Si a > 0, elle est ouverte vers le haut et possède un minimum. Si a < 0, elle est ouverte vers le bas et possède un maximum. Le signe de a ne signifie pas que toutes les valeurs de f sont positives ou négatives.

Les deux premières lignes se comprennent avec la fonction carré : x et −x ont le même carré. Pour f(x) = −2x² + 5, l’axe est x = 0 et le maximum vaut 5, atteint pour x = 0. Les points (1 ; 3) et (−1 ; 3) sont symétriques.

2. Racines et factorisation

Une racine de f est un nombre r tel que f(r) = 0. Graphiquement, elle est l’abscisse d’un point où la parabole rencontre l’axe horizontal. Une parabole peut ne pas couper cet axe, le toucher en un point ou le couper en deux points.

Vérifier une racine et retrouver une factorisation

Soit f(x) = 2x² − 10x + 8. On conjecture que 1 est racine : f(1) = 2 − 10 + 8 = 0, donc la conjecture est vérifiée.

On cherche alors une écriture (x − 1)(2x + d). En développant, on obtient 2x² + (d − 2)x − d. Le terme constant impose −d = 8, donc d = −8. Le coefficient de x vaut bien −10.

Ainsi f(x) = 2(x − 1)(x − 4). La règle du produit nul donne f(x) = 0 ⇔ x = 1 ou x = 4.

On vérifie toujours une factorisation en la redéveloppant. Une autre méthode consiste à reconnaître un facteur commun ou une identité remarquable : x² − 9 = (x − 3)(x + 3), tandis que x² − 6x + 9 = (x − 3)².

Périmètre du programme

Le calcul systématique des racines par le discriminant n’est pas au programme de première technologique 2026. On utilise les racines évidentes ou données, les formes factorisées, les graphiques et, au besoin, un outil numérique. Une équation sans solution réelle, comme x² + 1 = 0, ne doit pas être forcée dans une factorisation réelle.

3. Étudier le signe d’une forme factorisée

Pour f(x) = a(x − r)(x − s), avec r < s, chaque facteur change de signe à sa racine. On multiplie les signes, y compris celui de a. Le polynôme a le signe de a à l’extérieur des deux racines et le signe opposé entre elles.

Cas d’une racine double : a(x − r)² garde le signe de a des deux côtés de r et s’annule en r. Il n’y a pas de changement de signe. Par exemple, (x − 3)² ≥ 0 pour tout x.

PAUSE MÉMOIRE · JE ME SOUVIENS

Trouver les deux racines

Quelles sont les racines de f(x) = (x − 2)(x + 4) ?

Choisis une réponse.

Voir le raisonnement et la réponse

x − 2 = 0 donne 2 ; x + 4 = 0 donne −4. Les deux racines sont −4 et 2.

4. Trouver l’axe et le sommet

Deux points d’une parabole de même ordonnée sont symétriques par rapport à son axe. L’abscisse du sommet est donc le milieu de leurs abscisses. Une fois cette abscisse trouvée, on la remplace dans f pour calculer l’ordonnée du sommet.

À partir des racines

Pour f(x) = 2(x − 1)(x − 4), les points (1 ; 0) et (4 ; 0) sont à la même hauteur. L’axe est x = (1 + 4)/2 = 2,5. Ensuite f(2,5) = 2 × 1,5 × (−1,5) = −4,5.

Le sommet est S(2,5 ; −4,5). Comme a = 2 > 0, f décroît jusqu’à 2,5 puis croît. Son minimum est −4,5, atteint pour x = 2,5.

À partir d’une forme développée

Pour g(x) = x² − 6x + 5, on sait g(0) = 5. Cherchons l’autre point de même hauteur : g(x) = 5 ⇔ x² − 6x = 0 ⇔ x(x − 6) = 0. Les abscisses 0 et 6 donnent l’axe x = 3 ; g(3) = −4. Le sommet est donc (3 ; −4).

Si le terme en x est nul, l’axe est directement x = 0 ; inutile de chercher un deuxième point distinct par cette méthode.

5. Modéliser un bénéfice

Une entreprise fictive modélise son bénéfice, en centaines d’euros, pour x dizaines d’articles, par B(x) = −2(x − 1)(x − 5), sur [0 ; 6].

Résolution complète

Rentabilité. Les racines sont 1 et 5. Comme a = −2, B est positif entre les racines : B(x) > 0 pour 1 < x < 5. L’activité est bénéficiaire pour une production strictement comprise entre 10 et 50 articles, dans le modèle.

Meilleure production. Le milieu des racines est 3. B(3) = −2 × 2 × (−2) = 8. Le bénéfice maximal est 800 €, pour 30 articles. On a bien 3 ∈ [0 ; 6]. Les valeurs aux bornes sont B(0) = B(6) = −10.

Si la variable doit être entière, on ne retient que les valeurs entières compatibles avec le contexte. Pour une autre fonction dont le sommet ne correspond pas à un entier, on compare les deux entiers voisins admissibles.

6. Vérifier sa compréhension

Étudie h(x) = −(x + 2)(x − 4) : racines, signe, axe, sommet, variations.

Afficher la correction

Les racines sont −2 et 4. Le coefficient dominant est −1 : h est négative sur ]−∞ ; −2[ et ]4 ; +∞[, positive sur ]−2 ; 4[, nulle aux racines. L’axe est x = (−2 + 4)/2 = 1. h(1) = −3 × (−3) = 9 : le sommet est (1 ; 9), et 9 est le maximum. La fonction croît jusqu’à 1 puis décroît.

PAUSE MÉMOIRE · J’APPLIQUE

Reconnaître un maximum

Quelle est la valeur maximale de g(x) = −(x − 3)² + 9 ?

Choisis une réponse.

Voir le raisonnement et la réponse

−(x − 3)² ≤ 0, donc g(x) ≤ 9. Le maximum vaut 9 lorsque x = 3.

À retenir

La forme factorisée révèle les racines et le signe. La symétrie révèle le sommet. Le signe du coefficient de x² donne l’orientation de la parabole, pas le signe de toutes ses images.
