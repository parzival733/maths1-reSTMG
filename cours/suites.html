Dans cette leçon

Ce que tu vas savoir faire

Définir une suite, distinguer un rang d’un terme, calculer des valeurs par formule ou par récurrence, représenter les points et étudier une variation simple.

Appui : notion de fonction. On peut calculer et tracer les premiers termes directement sur papier.

Besoin d’un coup de pouce ? La méthode en 3 étapes

En clair : Une suite est une liste de nombres rangés par indice. Le rang n n’est pas la valeur du terme uₙ.

  1. Lis le rang de départ : u₀ et u₁ ne désignent pas le même terme.
  2. Si la formule est explicite, remplace n ; si elle est récurrente, pars du terme précédent.
  3. Écris les trois premiers termes pour vérifier que tu n’as décalé aucun rang.

1. Une fonction définie sur des rangs entiers

Une suite associe un nombre réel à chaque entier d’un ensemble de rangs. On écrit d’abord u(n), puis aussi un. Le nombre n est le rang ; u(n) est le terme de rang n. La suite entière se note (un), sans la confondre avec un terme particulier.

Une suite est un modèle d’évolution discrète : on observe à des instants séparés. Si n compte les mois après janvier, n = 0 représente janvier, n = 1 février, etc. Un rang n = 2,5 n’a pas de sens dans ce modèle mensuel, même si une formule pourrait être calculée pour 2,5.

Bien compter les termes

Si le premier rang est 0, les cinq premiers termes sont u(0), u(1), u(2), u(3), u(4). Le terme u(5) est le sixième. Une année civile s’obtient en ajoutant n à l’année initiale, pas en comptant n + 1 années écoulées.

2. Une formule explicite

Une définition explicite donne directement u(n) à partir de n. Pour u(n) = n² + 2 et n entier positif ou nul :

Calcul direct de u(n) = n² + 2
n01234
u(n)2361118

On peut calculer u(100) = 100² + 2 = 10 002 sans avoir calculé les termes précédents. Attention : u(n + 1) = (n + 1)² + 2, alors que u(n) + 1 = n² + 3. Remplacer n par n + 1 n’est pas ajouter 1 au résultat.

3. Une définition par récurrence

Une définition par récurrence donne le premier terme et une règle pour passer d’un terme au suivant. Les deux informations sont nécessaires. La relation v(n + 1) = 0,8v(n) + 50, seule, ne détermine pas une unique suite.

Un stock renouvelé

Un stock fictif contient 200 articles au départ. Chaque semaine, 20 % du stock est vendu, puis 50 articles arrivent. En notant v(n) le stock juste après la livraison de la semaine n, on obtient :

v(0) = 200 et v(n + 1) = 0,8v(n) + 50.

v(1) = 0,8 × 200 + 50 = 210 ; v(2) = 0,8 × 210 + 50 = 218 ; v(3) = 0,8 × 218 + 50 = 224,4.

Ce modèle produit des nombres réels : pour des articles indivisibles, il faut discuter une règle d’arrondi ou lire ces valeurs comme des quantités moyennes. Arrondir à chaque étape changerait la suite étudiée.

L’ordre des opérations compte : livrer 50 articles avant de vendre 20 % donnerait 0,8(v(n) + 50), soit une autre relation. Pour déterminer un terme lointain par récurrence, on calcule successivement tous les termes intermédiaires.

Le rang 0 est la valeur de départ ; on applique une fois la relation pour trouver le rang 1, deux fois pour le rang 2. Numérote les étapes pour éviter un décalage de rang.

PAUSE MÉMOIRE · JE ME SOUVIENS

Calculer avec une récurrence

Si u₀ = 7 et uₙ₊₁ = uₙ + 2, combien vaut u₃ ?

Choisis une réponse.

Voir le raisonnement et la réponse

u₁ = 9, u₂ = 11 et u₃ = 13. On effectue trois ajouts de 2 à partir de u₀.

4. Représenter et interpréter

Le graphique d’une suite est un nuage de points (n ; u(n)). Le rang est en abscisse, le terme en ordonnée. On ne trace pas automatiquement une courbe continue entre ces points : la suite n’est définie qu’aux rangs entiers.

Pour u(n) = n² + 2, on place (0 ; 2), (1 ; 3), (2 ; 6), (3 ; 11), (4 ; 18). Ces points montent de plus en plus vite et ne sont pas alignés. Un graphique aide à conjecturer une propriété ; une formule permet de la justifier.

Représenter une suite sans tableur

Pour u(n) = n² + 2, remplace n par 0, 1, 2, 3 : on obtient les points (0 ; 2), (1 ; 3), (2 ; 6) et (3 ; 11). Trace-les dans un repère en laissant les points séparés, car seuls les rangs entiers conviennent.

Pour une suite définie par récurrence, construis de la même manière un tableau avec les rangs 0, 1, 2… et une colonne pour chaque valeur calculée.

5. Sens de variation

Une suite est croissante lorsque u(n + 1) ≥ u(n) à chaque rang ; décroissante si u(n + 1) ≤ u(n) ; constante si les deux termes sont toujours égaux. Une suite peut aussi monter et descendre sans être monotone.

Étudier le signe de u(n + 1) − u(n).

Une démonstration valable pour tous les rangs

Pour u(n) = n² + 2, la différence vaut (n + 1)² + 2 − (n² + 2) = 2n + 1. Pour tout entier n ≥ 0, 2n + 1 > 0. La suite est donc strictement croissante.

Calculer seulement 2 < 3 < 6 < 11 ne suffisait pas : ces observations ne portaient que sur les premiers termes. Par exemple, w(n) = n(5 − n) monte d’abord, puis finit par descendre.

6. Reconnaître la nature d’une évolution

Une augmentation de la même quantité à chaque étape conduit à une suite arithmétique. Une multiplication par le même coefficient à chaque étape conduit à une suite géométrique. Ces deux familles seront étudiées dans les cours suivants.

Toutes les suites n’en font pas partie. Pour u(n) = n² + 2, les premières différences sont 1 puis 3 : elles ne sont pas constantes. Les premiers rapports sont 3/2 puis 6/3 : ils ne sont pas constants non plus. Cette suite n’est ni arithmétique ni géométrique. Le stock v(n) n’est pas non plus de l’une de ces deux natures : il combine une multiplication et un ajout.

Observer n’est pas toujours prouver

Deux différences distinctes suffisent à exclure la nature arithmétique. En revanche, deux différences égales ne prouvent pas qu’elles le seront toujours : pour démontrer une propriété, utiliser la relation de définition pour un rang quelconque.

7. Vérifier sa compréhension

On définit a(0) = 3 et a(n + 1) = 2a(n) − 1. Calcule les quatre premiers termes et explique comment trouver a(20).

Afficher la correction

a(0) = 3 ; a(1) = 5 ; a(2) = 9 ; a(3) = 17. Pour a(20), initialiser une variable à 3 puis répéter vingt fois « a ← 2a − 1 ». Les différences 2, 4, 8 ne sont pas constantes ; les rapports 5/3 et 9/5 non plus. La suite n’est donc ni arithmétique ni géométrique.

PAUSE MÉMOIRE · J’APPLIQUE

Distinguer rang et terme

Dans la suite vₙ = 5n + 1, quelle est la valeur du terme de rang 4 ?

Choisis une réponse.

Voir le raisonnement et la réponse

v₄ = 5 × 4 + 1 = 21. Le rang est 4, le terme est 21.

À retenir

Préciser le rang de départ, le premier terme et les unités. Une formule explicite permet un accès direct ; une récurrence décrit un passage au terme suivant. Une représentation suggère une propriété, mais ne la démontre pas.
