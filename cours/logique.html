À mobiliser toute l’année

Ce repère s’utilise dans les cours et les exercices de mathématiques. Il ne constitue pas une étape de révision à terminer avant de commencer les autres chapitres.

Tu apprendras à manipuler les ensembles et les intervalles, distinguer les formes d’une proposition et utiliser plusieurs types de raisonnement.

Besoin d’un coup de pouce ? La méthode en 3 étapes

En clair : Les mathématiques précisent sur quoi porte une affirmation. « Et », « ou », « pour tout » et « il existe » n’ont pas le même sens.

  1. Définis l’ensemble ou les propositions étudiées avant de calculer.
  2. Pour une intersection, garde les éléments communs ; pour une union, prends tous les éléments sans doublon.
  3. Pour réfuter une proposition universelle, trouve un seul contre-exemple qui la rend fausse.

1. Éléments, inclusion et cardinal

Un ensemble rassemble des éléments. Pour A = {1 ; 3 ; 5}, on écrit 3 ∈ A (« 3 appartient à A ») et 2 ∉ A. Un ensemble B est inclus dans A si chaque élément de B appartient à A ; on note B ⊂ A, ou B ⊆ A selon la convention utilisée. Ici, le symbole d’inclusion autorise l’égalité.

Le symbole ∅ désigne l’ensemble vide. Le cardinal d’un ensemble fini est son nombre d’éléments : Card(A) = 3. Dans un ensemble, répéter un même élément n’augmente pas le cardinal : {1 ; 1 ; 3} = {1 ; 3}.

Élément et sous-ensemble

On écrit 3 ∈ A, mais {3} ⊂ A. Le nombre 3 est un élément ; {3} est un ensemble contenant un élément. Ces deux écritures ne comparent pas des objets de même nature.

Les ensembles de nombres usuels sont ℕ (entiers naturels, ici avec 0), ℤ (entiers relatifs), ℚ (rationnels, quotients d’entiers à dénominateur non nul) et ℝ (réels). L’ensemble des décimaux à écriture finie est noté 𝔻. On a ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ. Par exemple −3 ∈ ℤ, 0,25 ∈ 𝔻, 1/3 ∈ ℚ mais 1/3 ∉ 𝔻, et √2 ∈ ℝ mais √2 ∉ ℚ.

2. Intervalles et opérations sur les ensembles

[a ; b] contient les réels entre a et b, bornes comprises. ]a ; b[ exclut les deux bornes. [a ; b[ inclut a mais exclut b. Les bornes infinies sont toujours ouvertes : [2 ; +∞[ signifie x ≥ 2.

L’intersection A ∩ B contient les éléments qui sont dans A et dans B. La réunion A ∪ B contient ceux qui sont dans A ou dans B, éventuellement dans les deux. Le complémentaire de A dans un univers E, noté E \ A ou Ā, contient les éléments de E qui ne sont pas dans A.

Deux intervalles

Pour A = [−2 ; 3] et B = ]1 ; 5], on a A ∩ B = ]1 ; 3] et A ∪ B = [−2 ; 5]. Le complémentaire de A dans ℝ est ]−∞ ; −2[ ∪ ]3 ; +∞[. Les valeurs −2 et 3 ne figurent pas dans ce complémentaire, car elles appartiennent à A.

La négation de « x > 3 » est « x ≤ 3 », pas « x < 3 ». La négation de « A et B » est « non A ou non B ». La négation de « A ou B » est « non A et non B ».

3. Couples et produit cartésien

Un couple est ordonné : (a ; b) et (b ; a) sont différents lorsque a ≠ b. Le produit cartésien A × B est l’ensemble des couples dont la première composante est dans A et la seconde dans B.

Deux choix successifs

Si A = {S ; E} et B = {1 ; 2}, alors A × B = {(S ; 1), (S ; 2), (E ; 1), (E ; 2)}. Pour des ensembles finis, Card(A × B) = Card(A) × Card(B), donc 2 × 2 = 4 ici.

Les coordonnées d’un point, les deux colonnes d’une série statistique et les résultats successifs d’une expérience utilisent cette idée de couple. Dans un tableau de données, permuter une seule colonne modifie donc les observations.

PAUSE MÉMOIRE · JE ME SOUVIENS

Comprendre l’intersection

Si A = {1 ; 3 ; 5} et B = {3 ; 4}, que vaut A ∩ B ?

Choisis une réponse.

Voir le raisonnement et la réponse

3 appartient à A et B ; aucun autre nombre n’est commun. Donc A ∩ B = {3}.

4. Le rôle d’une lettre et d’une égalité

Une lettre peut jouer plusieurs rôles. Dans f(x) = 2x + 3, x est la variable. Dans 2x + 3 = 11, x est l’inconnue à déterminer. Dans la famille f(x) = ax + 3, a est un paramètre : il choisit une fonction de la famille. Lorsqu’on développe formellement un polynôme, x peut être traité comme une indéterminée.

Une identité est vraie pour toutes les valeurs autorisées : (x + 1)² = x² + 2x + 1. Une équation demande pour quelles valeurs une égalité est vraie : (x + 1)² = 9. Une égalité entre deux nombres calculés, comme 2 + 3 = 5, n’est pas une nouvelle formule générale.

Un résultat approché s’écrit avec ≈ : 1/3 ≈ 0,333. Garder le signe = avec un arrondi peut fausser une chaîne de calculs ou une justification.

5. Implication, réciproque et contraposée

Une implication « si P, alors Q », notée P ⇒ Q, affirme que chaque fois que P est vraie, Q l’est aussi. La réciproque est Q ⇒ P. Elle peut être fausse même si l’implication initiale est vraie.

Un exemple avec les signes

Si x > 2, alors x² > 4 : c’est vrai. La réciproque « si x² > 4, alors x > 2 » est fausse : x = −3 donne x² = 9 > 4, mais −3 n’est pas supérieur à 2.

La contraposée est « si x² ≤ 4, alors x ≤ 2 ». Une proposition et sa contraposée ont la même valeur de vérité. La contraposée n’est pas la réciproque : elle inverse l’ordre et nie les deux assertions.

Dans P ⇒ Q, P est une condition suffisante pour Q ; Q est une condition nécessaire pour P. Dire « x est multiple de 4 » suffit pour conclure « x est pair ». Être pair est nécessaire pour être multiple de 4, mais n’est pas suffisant.

Une équivalence, P ⇔ Q, signifie que les deux implications sont vraies. Par exemple 2x + 3 = 11 ⇔ x = 4. Dans une résolution d’équation, chaque opération doit préserver les solutions pour que l’on puisse écrire ⇔.

6. Démontrer, réfuter et distinguer les cas

Une affirmation portant sur tous les nombres ne se démontre pas en vérifiant quelques valeurs. En revanche, un seul contre-exemple suffit à la réfuter. « Tous les nombres premiers sont impairs » est faux à cause de 2.

Pour une affirmation « il existe », un exemple bien vérifié suffit. Ainsi « il existe un réel x tel que x² = 9 » est prouvé en exhibant x = 3. La négation de « tous les éléments ont une propriété » est « au moins un élément ne l’a pas ».

Raisonnement par disjonction des cas

Pour montrer que x² ≥ 0 pour tout réel x, on sépare x ≥ 0 et x < 0. Dans le premier cas, le produit x × x est positif ou nul. Dans le second, le produit de deux nombres négatifs est positif. Les deux cas couvrent tous les réels.

Raisonnement par contraposée

Pour prouver « si un entier n² est pair, alors n est pair », on prouve la contraposée : si n est impair, n = 2k + 1, donc n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1 est impair.

Raisonnement par l’absurde

Pour montrer qu’il n’existe pas de plus grand entier naturel, supposons qu’un entier N soit le plus grand. Alors N + 1 est encore naturel et supérieur à N : contradiction. L’hypothèse de départ était donc impossible.

7. Logique et auto-évaluation

Dans un exercice de logique, « avoir au moins 16 ans et moins de 18 ans » correspond à l’intervalle [16 ; 18[. La condition contraire est « avoir moins de 16 ans ou au moins 18 ans ». On traduit directement les mots « et », « ou », « non » en conditions mathématiques.

La proposition « si x = 3, alors x² = 9 » est-elle une équivalence ? Quelle est sa réciproque ? Quelle condition supplémentaire permet une équivalence ?

Afficher la correction

L’implication est vraie, mais sa réciproque « si x² = 9, alors x = 3 » est fausse sur ℝ, car x = −3 convient aussi. Sur [0 ; +∞[, on a en revanche x² = 9 ⇔ x = 3. Le domaine fait partie du raisonnement.

PAUSE MÉMOIRE · J’APPLIQUE

Ne pas confondre une implication et sa réciproque

Quelle proposition est toujours vraie pour un réel x ?

Choisis une réponse.

Voir le raisonnement et la réponse

Tout x > 3 est bien > 1. La réciproque n’est pas vraie pour x = 2 ; x² = 4 autorise aussi x = −2.

À retenir

Préciser l’univers et le domaine. Distinguer « et » de « ou », implication de réciproque, exemple de démonstration. Une bonne justification indique pourquoi la conclusion vaut pour toutes les valeurs concernées.
